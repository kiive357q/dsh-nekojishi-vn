# DSH Nekojishi VN · Agent の作業に、物語の舞台を

[简体中文](README.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md)

DeepSeek Harness の作業画面をビジュアルノベル風にする非公式プラグインです。背景、左右のキャラクター、透過した会話表示、画面下部の入力欄を組み合わせ、実際のタスク状態に応じて表情を変えます。モデル、プロジェクト、ツール、権限、質問への回答処理は DSH の機能を使用します。

## 特徴

- 思考中、実行中、返信中、回答待ち、失敗、ターン終了、目標完了を区別します。
- キャラクターは画面下端に追従し、会話の幅は輪郭の安全領域に合わせて調整されます。サイドバーを開くと再配置し、リソースの全画面表示では背面を覆ってぼかします。
- モデルとキャラクターを別々に選択できます。左右とも「なし」を選べます。単一キャラクター、または左右が同じ場合は対応する話し方の skill を利用できます。
- プレーヤーには再生位置、音量、シャッフル、ローカル音源とプレイリストの読み込みがあります。再起動時に自動再生しません。
- 標準表示に戻せます。プラグイン管理画面と自動化タスク画面では、キャラクターとアバターを一時的に隠します。

## ダウンロードして使う

公開版の初期状態は、オリジナル背景 3 点と短い合成音楽 1 曲を備えたシンプルな舞台です。代替キャラクターは表示しません。基本 UI にゲームファイルは不要で、本編のキャラクターは自分のゲームから任意で取り込みます。

確認済みのホストは、Windows 向け公式 DSH 0.2.1-rc.2 です。ZIP を展開するかリポジトリを clone し、トレイから DSH を終了して、プロジェクトのフォルダーで実行します。

```powershell
.\install.ps1
```

ビルド済みファイルを同梱しているため、通常のインストールに Node、npm、Python の追加導入は不要です。公式デスクトップアプリに含まれるランタイムを使用します。ポータブル版では `-DesktopExe`、CLI の Web プロファイルでは `-Profile web` を指定できます。

## 任意：自分のゲームから取り込む

```powershell
npm ci
python -m pip install -r scripts/requirements.txt
python scripts/import-resources.py --game-dir '自分の Nekojishi インストール先'
npm run build
.\install.ps1 -IncludeLocalGameResources
```

現在対応するのは Nekojishi 1.06s の構成です。背景 107 点、音楽 25 曲、キャラクター画像、中国語の分岐付き引用をローカルに生成します。ゲームの元ファイルは変更しません。生成されたゲーム素材、台詞データ、素材入りパッケージは、別途許可がない限り公開しないでください。

公開する role skill は手作業でまとめた表現ルールです。ゲームの台詞データや学習済みモデルの重みは含みません。技術的な作業能力と権限を維持し、ローカルの出典がない場合は物語の内容を確認済みと主張しません。

コードとオリジナルのデモ素材は MIT ライセンスです。ゲームの画像、音楽、台詞などの権利は含まれません。[第三者コンテンツについて](THIRD_PARTY_NOTICES.md)を参照してください。

現在の UI 表示は簡体字中国語です。日本語版は説明文書であり、UI 全体の日本語対応を意味しません。他の OS、DSH バージョン、外観プラグインとの組み合わせは未検証です。詳細は[メイン文書](README.md)と[検証記録](docs/VALIDATION.md)を参照してください。
