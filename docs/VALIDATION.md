# 验证范围

版本：0.4.0-alpha.1，基于本机主题 0.3.2。

- 公开版构建通过；10 项自动检查通过，包含状态判定、人物选择、歌单路径、角色表达绑定与缺失资源回退。
- 本机资源导入实际通过，读取用户本机 Nekojishi 1.06s；原版资源未放入公开清单。
- 公开轻量包包含 3 张原创场景和 1 段 16 秒合成音乐，不附替代人物。人物仅在用户本机导入原版资源后显示。
- Windows install.ps1 的独立打包已执行成功；正式客户端路径识别已核对。
- 独立官方 0.2.1-rc.2 Web Host 已从预构建 .tgz 安装成功，使用独立 DSH_HOME，无游戏、凭据或正式聊天数据。
- 公开版 6 项浏览器检查通过，且无浏览器运行时错误：默认演示加载、三张场景和独立人物选择、合成音乐播放及 Range 206、全局页面隐藏人物、5 种窗口尺寸、切换原生界面保留输入组件与草稿。
- 测试宿主通过官方配置关闭凭据 onboarding 提示，未录入或调用真实模型账户；这项 UI 回归没有验证模型提供方登录与计费功能。
- 本机原版资源模式亦完成 6 项浏览器检查，无浏览器运行时错误：107 张背景、原版人物、25 首音乐，以及上述交互与窗口适配。
- 三张公开快照展示隔离宿主导入本机游戏后的主界面、人物场景选择、左栏与播放器，不代表公开安装包包含原版资源。
- 原主题的 16 项浏览器回归、5 项功能回归属于导入原版资源的本机版，不代表公开版已在所有平台完成同等验证。
- 没有验证 macOS、Linux、第三方 DSH 客户端或任意主题插件组合。

GitHub 发布、社区收录和测试通过是三个不同状态，不能互相替代。
